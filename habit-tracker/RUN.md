## 一、这个项目是什么

一个纯网页版的自律助手：时间轴待办 + 心情三选一 + 无压力思考 + 周月报。
**无后端、无安装依赖、无登录**——所有数据存在浏览器 localStorage 里（约 5MB）。

## 二、怎么跑起来（3 步）

> 前提：电脑装了 Python 3（Windows 一般自带；Mac/Linux 自带）。

**第 1 步：打开终端，进入仓库根目录**

```
cd C:\Users\Lenovo\Desktop\vibe-coding-course
```

> 关键点：必须停在 `vibe-coding-course` 这一层（仓库根），不要进 `habit-tracker/` 里面。
> 下面第 2 步的命令会以当前目录作为网站的"根"，这样页面地址和 GitHub 上的目录结构一致。

**第 2 步：启动本地服务器**

```
python -m http.server 8765
```

- `8765` 是端口号（避开常用的 80/3000/8080，减少撞车）
- 看到 `Serving HTTP on ...` 字样就是成功了
- 这个窗口**不要关**，关了网站就停了；停止服务按 `Ctrl + C`

**第 3 步：浏览器打开页面**

```
http://localhost:8765/habit-tracker/frontend/index.html
```

> `localhost` 的意思就是"本机自己"——这个地址只有你的电脑能打开，别人访问不了，数据也在你浏览器里，隐私安全。

## 四、常见问题（FAQ）

| 症状 | 原因 | 解法 |
|------|------|------|
| 打不开页面，浏览器一直转 | 第 2 步的服务器没启动，或窗口被关了 | 重做第 2 步 |
| 提示"端口被占用"（Address already in use） | 8765 被别的程序占了 | 换个号：`python -m http.server 8766`，地址栏也改成 8766 |
| 页面开了但样式全乱/白屏 | 没从仓库根目录启动，相对路径断了 | 回到第 1 步，确认当前目录再启动 |
| 想清空所有数据重来 | 数据在 localStorage 里 | 浏览器按 F12 → Application（应用）→ Local Storage → 删除 `habit-tracker-v1` |
