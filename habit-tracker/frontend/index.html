使用指南

  • 加待办：在「今天」输入内容，可选时间点和象限，点 ＋ 或回车
  • 四象限：重要且紧急 · 重要不紧急 · 紧急不重要 · 不重要不紧急；不选就是普通待办
  • 完成 / 删除 / 移动：点圆圈打勾，再点恢复；点 ··· 可以删除（会先确认）或移动到其他日期
  • 思考：切到「思考」页，点底部中间的 ＋ 随手写一条（Ctrl+Enter 可快捷保存）；长的自动折叠，点「展开全文」看全
  • 应用：切到「应用」页看小工具列表——待办事项可直达「今天」页；专注计时已可用（番茄钟 25/短专注 15/休息 5），其余按天逐步开放
  • AI 洞察：「思考」页顶部的 ✨，五种视角（默认/价值澄清/MBTI/每日回顾/随机漫步）——本地规则拼装，数据不上传，MBTI 仅供自娱
  • 心情：每天第一次打开会问一句，可跳过；想改就点「最近情绪」里今天的格子
  • 数据：只存在这台设备的浏览器里，清缓存会一起清掉
