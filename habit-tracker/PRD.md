## 一、产品定位（一句话）

> 一个纯网页版的自律助手：早上在时间轴上排今天的待办，做完打勾并选一个今日状态（笑脸/平静脸/哭脸），随手写一点思考、答一个小问题；到一周或一个月时，收到一份"你是一个怎样的人"的夸夸报告。

## 二、目标用户与核心问题

**目标用户**：自律的人（沿用 research.md 的画像：主动想管理自己，不需要被"哄"，讨厌复杂和打断）

**他们现在的问题**：

| # | 问题 | 现有产品的缺陷（调研结论） |
|---|------|---------------------------|
| 1 | 每天写 to-do list，但列表是散的，看不出"今天的安排"长什么样 | 多数 to-do 应用是"清单视图"而非"时间轴视图"（Taskito 官网对比页明确指出的差异点） |
| 2 | 只能记录"做了什么"，记录不了"今天感觉怎样" | everyday.app / 小日常只有"是/否"打卡，没有情绪维度 |
| 3 | 想留一点思考，但正经笔记工具（标题、排版、分类）压力太大 | flomo 的核心理念："像发消息一样无压力记录"，先记录后整理 |
| 4 | 坚持了很久，但没有任何东西告诉他"你是一个怎样的人" | 三家竞品都只有完成率/连胜数字，缺少人格化的正向反馈 |

## 三、产品原则（从调研继承 + 本次新增）

1. **三秒原则**：任何每日动作（打勾、选心情、写一句）≤ 3 秒能完成入口操作
2. **无惩罚**：不选心情、不写思考、漏答问题都不算"断"，什么都不发生（everyday.app "跳过不惩罚"的成熟设计）
3. **自律者不需要游戏化**：不做经验/金币/等级（Habitica 教训，research.md 关键洞察 1）
4. **记录比整理重要**：思考卡片不强制分类，写了就算赢（flomo 理念）
5. **正向反馈人格化**：报告的语气永远是"夸夸和鼓励"，基于事实夸，不空洞吹捧

## 四、页面结构（三个页面，一页一个核心场景）

```
┌─ 今天（默认首页）─┐   ┌─ 思考 ─────────┐   ┌─ 我的 ─────────┐
│ 心情弹窗(首次)   │   │ 每日一问        │   │ 头像 / 名字     │
│ 时间轴 to-do     │   │ 思考卡片流      │   │ 使用天数        │
│                  │   │ 周/月报告入口   │   │ 情绪板块(7天)   │
└──────────────────┘   └────────────────┘   │ 设置 / 使用指南  │
                                            └────────────────┘
```

底部固定导航：**今天 · 思考 · 我的**（三个词，零学习成本）。

## 五、功能需求（每个功能 = 用户动作 + 可观察结果）

### F1 时间轴 to-do（首页主体，参考 Taskito）

> Taskito 的核心价值（官网及对比资料）：把任务按时间排布在一天的轴上，"看到什么在什么时候发生"，而不是一串散列表。

| 用户动作 | 可观察结果 |
|---------|-----------|
| 点击"+"输入待办内容，可选一个时间点（如 09:00） | 待办卡片出现在时间轴上对应时间的位置；未设时间的排在"未安排"区（轴底部） |
| 添加时选择象限：Q1 重要且紧急 / Q2 重要不紧急 / Q3 紧急不重要 / Q4 不重要不紧急，或不选 | 卡片左侧出现对应颜色的象限标记：Q1 橙红 / Q2 琥珀 / Q3 蓝灰 / Q4 石板灰；不选的为第五类"未分类"（雾蓝）。象限为可选字段，选了按象限色标注，不选按默认色标注 |
| 点击待办前的圆圈 | 圆圈变成实心 + 文字划线置灰，卡片轻微下沉（完成的视觉仪式） |
| 再次点击已完成的圆圈 | 恢复为未完成（当天内可反悔） |
| 点"···"再点删除 | 弹确认框，确认后卡片从时间轴消失 |
| 点"···"再点"移动到其他日期" | 弹出日期选择弹窗（显示待办内容，默认目标为后一天），选好日期点确认后，卡片从当前日期消失、出现在目标日期；空日期/同一天给出轻提示，不关弹窗 |
| 左右滑动或点日期切换 | 时间轴翻到前一天/后一天（后一天只能看不能提前打勾） |

**规则**：
- 时间轴只有"今天 ± 若干天"的浏览能力，**只能对今天打勾**（继承 v1 的简化规则，砍掉补卡）
- 刷新/关浏览器再开，今天的待办和勾选状态不丢
- 不做拖拽改时间（Taskito 的拖拽是它付费级体验，我们 28 天做不动，改为删除重加）
- 象限只是视觉标注，不改变任何排序/提醒/统计逻辑（四象限时间管理法在 MVP 中仅做分类标记）

### F2 今日心情（五种，自动弹窗，参考 suki）

> suki 心情日记的机制（北航软件站功能说明）：选一个表情 → 日历对应日期显示该表情 → 点表情回看当天内容。我们移植这套"表情 → 回看"到单人自律场景，并把入口前移到"打开页面就问一句"。

| 用户动作 | 可观察结果 |
|---------|-----------|
| 当天第一次打开"今天"页且**还没选过心情** | 自动弹出心情弹窗：五个表情按钮 😢伤心 / 😞忧郁 / 😐平静 / 😌惬意 / 😄喜悦，可点"先不选"跳过 |
| 点其中一个表情 | 弹窗关闭；"我的-情绪板块"里今天的格子显示该表情；选伤心/忧郁时情绪板块下方出现安抚句（如"难过的时候，允许自己慢一点"） |
| 想换心情 | 进"我的-情绪板块"，点今天的格子重新打开弹窗；当天心情**覆盖更新**（一天只有一个最终心情，以最后一次为准） |
| 点"先不选" | 弹窗关闭，本次打开不再自动弹；无任何提示或惩罚 |

**规则**：心情一天一条，不存历史修改；伤心、忧郁均只配安抚文案，不出现任何负面/警告语（无惩罚原则）。

### F3 今日思考（参考 flomo）

> flomo 的可借鉴点：卡片式、无标题无排版、聊天式输入、写完即存。我们不抄它的标签体系和热力图（整理能力放后续）。

| 用户动作 | 可观察结果 |
|---------|-----------|
| 进入"思考"页，看到今天的**每日一问**（如"今天有什么小确幸？"） | 问题卡片置顶显示，下面直接是输入框，光标已就位 |
| 输入文字，点"记下来" | 新卡片插入卡片流顶部，带当天日期时间戳 |
| 点击历史卡片 | 展开全文；再次点击收起 |
| 不答每日一问，直接写别的 | 也完全可以——每日一问只是"起手式"，不是必答题（无惩罚原则） |

**每日一问规则**：
- 问题池内置约 30 个生活向问题（示例："最近哪件小事让你开心？""你今天为自己做了什么？""这周想对谁说声谢谢？""如果今天重来一次，你会改变什么？""最近在期待什么？"）
- 每天随机出 1 个，当天不重复；问题池循环使用
- 换一题：问题旁有"换一个"按钮（最多换 3 次，防刷完题库）

### F4 报告（周报 / 月报，夸夸式）

| 用户动作 | 可观察结果 |
|---------|-----------|
| 满 7 天后打开"思考"页 | 出现"本周报告"入口卡片 |
| 点开周报 | 报告页展示：本周完成待办数、心情表情分布（几个笑脸几个哭脸）、思考卡片数、连续记录天数 |
| 滚动到报告底部 | 出现**人格化总结**："你是一个 ___ 的人"+ 一段基于上述数据的夸夸文案（见下方生成规则） |
| 满 30 天后 | 同样出现"本月报告"，结构同周报但统计范围换成月 |

**夸夸文案生成规则（MVP 简化版，规则拼装而非 AI）**：
- 完成率 ≥ 80% → "你是一个说到做到的人"
- 笑脸占比最高 → "你是一个能在日常里找到快乐的人"
- 哭脸出现但仍在记录 → "你是一个难过也不放弃的人"
- 思考卡片 ≥ 5 条 → "你是一个愿意和自己对话的人"
- 各条可叠加，最后统一收尾一句鼓励："这 N 天的证据都存在这里，你比自己以为的更自律。"
- 数据不足（如 < 3 天心情）→ 按已有数据出报告，缺项不编造

### F5 我的（MVP 实用版，参考 flomo 的设置）

| 用户动作 | 可观察结果 |
|---------|-----------|
| 打开"我的"页 | 依次看到：头像（emoji 占位）、名字、使用天数、情绪板块、通用设置、使用指南 |
