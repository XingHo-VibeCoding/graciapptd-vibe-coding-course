# 比赛精进方案（吉祥物 · 指南压缩 · 积分换装 · PWA）

- 版本：v1.0（2026-10-27）
- 状态：**待用户确认参数后开工**（一次一个任务）
- 依据：用户 2026-10-27 需求（总览 → 手机软件化 → 吉祥物替代指南 → 积分换装游戏化）
- 形象定稿：**C 融合版**（贱萌胖矮体型 + app 配色），原型 = 用户自家橘白小奶猫照片

---

## 一、目标与判断

| 用户诉求 | 本方案的答案 | 判断依据 |
|---|---|---|
| 想当手机软件用 | **PWA**（可添加到主屏、全屏、离线可开） | 单文件网页架构下成本最低；不转小程序（等于重写）、不先打包 APK（只是 PWA 的壳） |
| 使用指南冗杂 | **橘猫首访引导 + 指南压成 3 行** | 现有指南 8 条且**已过时**（仍写已删除的勾选圈、已下线的三种洞察视角） |
| 想要 AI 形象 | **C 版橘猫 + 极简版双形态** | 大图卖萌、小图识别；全部内联 SVG，随主题变色 |
| 想有游戏性 | **积分 + 换装** | 习惯养成类产品最有效的留存循环；且换装可用 SVG 图层零素材成本实现 |
| 想参赛 | 差异化 = 有真实故事的 IP + 严谨工程 + 可演示的成长闭环 | 功能宽度已够，缺的是记忆点 |

**不做**（本期范围外，防止爆炸）：不做多宠物、不做排行榜/社交、不做付费、不做云端同步换装数据（与打卡同步同一批任务，见 §七）。

## 二、吉祥物系统

### 2.1 形象规范（落地即 SVG 手绘，AI 图仅作设计稿）

| 项 | 值 | 说明 |
|---|---|---|
| 描边 | `#5C4A3D`（= 正文色 `--ink`），线宽约 4/100 单位 | 与卡片、图标同一支笔；**禁用纯黑** |
| 毛色 | 主体 `#F0C08A`，虎斑 `#D99A4E` | 落在主色 #E6A23C 邻域，不抢内容 |
| 白毛 | 胸腹 `#FBF6EA`（= 次级面） | |
| 鼻子 / 耳内 | `#F2A9A0` / `#E8A08F` | 唯一的暖粉，控制在小面积 |
| 眼睛 | 琥珀 `#C98A3E` + 深瞳 `#5C4A3D` | |
| 深色主题 | 描边随 `--ink` 变浅（#e9ecef），毛色整体提亮一档 | 复用图标那套 currentColor / 变量思路 |
| 最小尺寸 | 完整版 ≥ 48px；< 48px 用极简版 | 小尺寸细节会糊 |

### 2.2 两种详细度

| 版本 | 用途 | 尺寸 |
|---|---|---|
| **完整版**（C） | 引导气泡头像、薯条洞察署名、换装主角、完成彩蛋 | 48–160px |
| **极简版**（D） | 顶部提示、空状态、加载中、PWA 图标 | 24–48px |

### 2.3 首批表情（5 个，SVG 复用同一身体，只换脸）

| 表情 | 触发场景 | 语气示例（待命名后替换 `{猫名}`） |
|---|---|---|
| 默认·淡定斜眼 | 常驻、气泡未说话时 | 「在呢。」 |
| 开心·眯眼 | 完成待办 / 打卡满圈 | 「哼，还行吧。」 |
| 鼓励·温柔 | 连续 3 天没完成 / 洞察关怀 | 「今天没做完也没关系。」 |
| 困·半闭眼 | 深夜（22:00 后）打开 | 「这么晚还不睡？」 |
| 得意·星星眼 | 换装成功 / 连续 7 天 | 「这身不错吧。」 |

### 2.4 出现位置（逐处替换）

1. **首访引导**（新用户第一次打开）：3 步气泡，替代长指南（见 §三）
2. **薯条洞察卡片**：文案前加头像 + 署名「{猫名} 说」，关怀语从"系统提示"变成"猫说的话"
3. **今日空状态**：列表为空时，猫 + 一句「今天还没有安排」
4. **打卡完成**：满圈瞬间猫在卡片角落冒一下（不打断操作，1.5s 自动消失）
5. **积分/换装页**：主角大图 + 配饰叠加
6. **PWA 图标**：极简版 + 奶油底

## 三、使用指南压缩

### 3.1 现状问题

「我的」页 `使用指南` 现有 8 条静态文字，两个硬伤：

- **已过时**：第 3 条仍教「点圆圈打勾」（v1.2 已删勾选圈，改为点整行）；第 6 条仍说洞察有五种视角（v1.6 只剩默认 + MBTI）
- **信息密度错配**：把「怎么加待办」这种一次性知识和「数据存哪」这种偶尔要查的知识混在一起

### 3.2 目标形态

| 位置 | 内容 | 形态 |
|---|---|---|
| 首访（仅一次） | 3 步：① 在这里写今天要做的事 ② 点整行就算完成 ③ 想要长期坚持就建「打卡」 | 猫气泡 + 半透明蒙层 + 高亮目标元素，可跳过 |
| 「我的」页 | **3 行**摘要：加待办 / 点整行完成 / 打卡在筛选栏 | 静态文字，不超过 3 行 |
| 「我的」页底部 | 「让{猫名}再教我一遍」 | 按钮，重播首访引导 |

**判定标准**：指南文字总量 ≤ 120 字（现约 400 字），且**不含任何会随版本失效的操作细节**——细节交给引导（可随代码同步更新），文字只留稳定事实。

### 3.3 首访触发规则

- `localStorage` 记 `onboarded: true`，只自动弹一次
- 引导可随时从「我的」页重播
- 首次进入「打卡」筛选时单独一条提示（只一次），避免用户找不到新建入口

## 四、积分与换装（游戏化）

### 4.1 积分规则（本地计算，防刷）

| 行为 | 积分 | 限制 |
|---|---|---|
| 完成一条待办 | +5 | 同一待办同日只加一次；取消完成（点第二下）**扣回** 5 |
| 打卡一次 | +3 | 每天每项按 `perDay` 上限计分，超出不加 |
| 打卡满圈（当天达标） | 额外 +5 | 每项每天一次，撤回满圈则扣回 |
| 连续 7 天有任意完成 | +20 | 一次性奖励，按日期窗口判定，不重复发 |

- 记分基准 = 已存在的数据（`todos[].done` + `habitLogs`），**不新增"事件表"**，避免两套真相
- 每日结算防重复：`pointsAwarded[date] = {todoIds:[], habitDone:[], streak:false}`

### 4.2 换装

| 项 | 规则 |
|---|---|
| 首批配饰 | 6 件：围巾 30 / 小帽 45 / 圆眼镜 60 / 领结 75 / 小背包 100 / 斗篷 150 |
| 获取 | 积分达到即解锁（不做消耗制，**只涨不扣**——避免用户因换装而后悔，习惯类产品不宜罚款） |
| 穿戴 | 可同时穿「头 + 身」两件，避免图层互相打架 |
| 实现 | 每件配饰 = 一段 `<g>`，锚点固定在 SVG 的 `head` / `neck` 两个组，换装 = 切换 `display` |
| 展示 | 积分条在「我的」页顶部；点开进「衣柜」（猫 + 6 格商品，未解锁显示所需积分） |

### 4.3 数据

并入现有 `habit-tracker-v1` 键，新增：
```js
pet: { points: 0, owned: [], wearing: { head: null, body: null }, awarded: {}, onboarded: false }
```
`fillDefaults` 补旧数据（`pet` 缺失时初始化），**不改动 todos/habits 结构**。

### 4.4 语气边界（重要）

- 猫只说短句，**不超过 20 字**，不用感叹号堆砌，不道德绑架（禁「你今天又没完成」）
- 未完成时不掉分、不惩罚、猫不生气——只有「温柔鼓励」和「淡淡的傲娇」两种情绪

## 五、PWA（手机软件化）

| 项 | 内容 |
|---|---|
| `manifest.json` | name 自律计划、short_name 自律、`display: standalone`、`theme_color #FEFDF9`、`background_color #FEFDF9`、192/512 图标（极简猫） |
| Service Worker | 预缓存 `index.html` + 图标；导航请求 **网络优先、失败回落缓存**（保证线上更新能立即生效，又支持离线打开） |
| 安装提示 | 首次访问后延迟出现一条轻提示「添加到主屏，像 App 一样用」（可关闭，7 天不再弹） |
| 安全 | SW 只缓存静态资源，**不缓存 `/api/*`**（避免读到旧数据） |
| iOS | 说明「Safari → 分享 → 添加到主屏幕」（iOS 不支持自动安装提示） |

**验证方式**：Chrome DevTools → Application → Manifest 无报错、Service Worker activated；断网刷新仍能打开页面；手机上添加到主屏后无地址栏。

## 七、验收标准（可检查）

1. 首页/我的页**搜不到**「点圆圈」「五种视角」等失效文案（静态断言）
2. 首访引导只自动出现一次；「让猫再教我一遍」能重播
3. 指南文字总量 ≤ 120 字（脚本数字符）
4. 完成 → 积分 +5；再点取消 → 回到原值（断言）
5. 同日重复完成同一待办不重复加分
6. 打卡超过 `perDay` 不再加分；撤回满圈扣回 5
7. 6 件配饰按积分解锁；穿戴两件后 SVG 中对应 `<g>` 可见
8. `manifest` 解析无错、SW `activate` 成功、断网可打开页面
9. 深浅两主题下猫的描边都可见（对比度检查）
10. 全部旧数据（无 `pet` 字段）能正常加载，不报错
